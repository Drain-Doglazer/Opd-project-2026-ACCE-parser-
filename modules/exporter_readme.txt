==АРХИТЕКТУРА==

1. Экспортер загружает готовый шаблон (.xlsx), полученный из самого ACCE,
копирует его служебные строки (1–10) и маркер LAST ROW, а данные вставляет строго перед этим маркером.

2. Для каждого типа оборудования (CP, FN, VT и т.д.) создается отдельный лист с именем, совпадающим с кодом Icarus.

3. Перед записью проверяется уникальность тегов (user_tag). Если есть дубли, добавляются суффиксы (-A, -B).
Также формируется лист VALIDATION для аудита.

4. Возвращает информацию о загруженных данных

==ЗАГЛУШКИ==

Структура заглушки:
    Строки 1–10 заполнены текстом "Header Row N".
    Строка 11 содержит заголовки колонок (ACTION, ITEM_SYMBOL и т.д.).
    Последняя строка содержит текст "LAST ROW".

2. Заглушка данных (Mock Data)
Находится в файле tests/test_exporter.py, функция create_mock_data.
Вручную создает 4 объекта ACCERecord (насос, вентилятор, котел, реактор) и 1 невалидный объект.
Проверяет логику экспорта без парсера
