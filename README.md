# ⚙️ ACCE Equipment List Parser

Streamlit-приложение для автоматического парсинга перечней оборудования и подготовки данных для импорта в **Aspen Capital Cost Estimator (ACCE)**.

---

## Установка и запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

CLI-режим:

```bash
python run_parser.py input.xlsx --template master-template.xlsx --area "Unit 100"
```

## Пайплайн обработки

```
Входной файл (.xlsx / .pdf / .docx)
         │
         ▼
   [parse_xlsx / parse_pdf / parse_docx]
         │  список записей EquipmentRecord
         ▼
   [classify]  — определяет ACCE_ITEM_SYMBOL и ACCE_ITEM_TYPE
         │
         ▼
   [validate_all]  — проставляет IS_VALID / ERRORS / WARNINGS
         │
         ▼
   [write]  → <name>_parsed.xlsx
         │
         ▼  (только при --template)
   [export]  → <name>_acce.xlsx  (листы по символам ACCE)
```

## Колонки parsed.xlsx

| Колонка | Описание |
|---|---|
| `USER_TAG` | Тег оборудования из исходного файла |
| `DESCRIPTION_RU` | Наименование на русском |
| `PARENT_AREA` | Зона установки |
| `ACCE_ITEM_SYMBOL` | Символ типа оборудования в ACCE (HE, PU, VE, …) |
| `ACCE_ITEM_TYPE` | Подтип оборудования |
| `QUANTITY` | Количество единиц |
| `IS_VALID` | `YES` / `NO` |
| `ERRORS` | Текст ошибок валидации |
| `WARNINGS` | Текст предупреждений |

## CLI-использование

```bash
# Только парсинг
python run_parser.py "Samples 1.xlsx"

# Парсинг + экспорт в ACCE
python run_parser.py "Samples 1.xlsx" \
  --template master-template.xlsx \
  --area "Unit 100" \
  --output result_acce.xlsx

# Флаги
#  -o / --output    путь к ACCE-файлу
#  -t / --template  путь к master-template.xlsx
#  -a / --area      PARENT_AREA по умолчанию
#  --parsed         путь к промежуточному parsed.xlsx
#  -v / --verbose   включить debug-логирование
```
